# ALFA PULSE — кабинет сотрудника банка

**ALFA PULSE Staff** — интерфейс сотрудника банка для рассмотрения кредитных заявок юридических лиц и малого бизнеса.

**Демонстрация:** [Открыть кабинет сотрудника](https://vagner2203-cell.github.io/alfa-pulse-staff/)

## Основные возможности

- Просмотр очереди кредитных заявок и ключевых показателей.
- Поиск заявок по идентификатору, компании и ИНН.
- Просмотр финансовых параметров, скорингового балла и причин оценки.
- Демонстрация решений: одобрение, отказ, запрос документов и предложение альтернативных условий.
- Просмотр истории заявки и экспорт данных в CSV.

## Как работает прототип

Интерфейс реализован на HTML, CSS и JavaScript и адаптирован для работы на компьютерах и ноутбуках.

В текущей версии используются синтетические данные. Действия с заявками демонстрируются на стороне интерфейса и не сохраняются после перезагрузки страницы.

**Текущий статус:** демонстрационный интерфейс кабинета сотрудника. Интеграция с сервером, постоянное хранение заявок и полноценная авторизация сотрудников требуют отдельной реализации и проверки.

## Запуск

Откройте `index.html` в современном браузере.

Для локального запуска через Docker выполните в корне проекта:

```bash
docker compose up --build -d
```

После запуска откройте `http://localhost:8080/`.

## Структура проекта

- `index.html` — интерфейс кабинета сотрудника.
- `docs/` — архитектура, модель данных, API-контракт и техническая документация.
- `examples/` — синтетические примеры заявок.
- `tests/` — план и автоматизированные проверки.
- `Dockerfile`, `docker-compose.yml` — конфигурация контейнерного запуска.

## Важное ограничение

Проект представляет вклад кабинета сотрудника в ALFA PULSE. Он не является самостоятельно работающей банковской системой и пока не обеспечивает полный сквозной процесс кредитования.

Реальная обработка заявок, серверный скоринг, проверка документов и синхронизация с клиентским кабинетом должны подтверждаться интеграционными испытаниями.
