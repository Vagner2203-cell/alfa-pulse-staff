# THIRD_PARTY_NOTICES — ALFA PULSE Staff Demo

## Продукт и происхождение компонентов

- **Страница интерфейса:** HTML5, CSS и JavaScript без внешних frontend-пакетов или CDN. Код прототипа включён в репозиторий.
- **Шрифт:** `Inter` указан как предпочтительный, но не загружается из стороннего источника; при его отсутствии используются системные шрифты браузера.
- **Графика:** встроенная в HTML SVG-пульс-линия и текстовые символы Unicode. Внешние изображения в сайт не встроены.
- **Docker (опциональный запуск):** базовый образ `nginx:1.27.5-alpine`; NGINX распространяется под лицензией BSD-2-Clause, Alpine Linux включает компоненты с отдельными лицензиями. Лицензии и состав содержимого образа необходимо учитывать при перераспространении.
- **Проверка:** тесты на встроенном `node:test` (Node.js), без установки npm-пакетов.
- **Схемы:** исходники диаграмм в формате DOT; PNG получены Graphviz при подготовке пакета. Graphviz распространяется по Eclipse Public License 1.0.

## Имитируемые системы и данные

Компании, ИНН, сумма финансирования, скоринговые оценки, статусы и история — **синтетические**. Следующие процессы имитируются только в памяти браузера: просмотр данных, решение сотрудника, запрос документов, альтернативные условия и экспорт CSV.

**Не подключены:** действующая банковская система, реальный кредитный скоринг, API, PostgreSQL, электронная подпись, реальная выдача, LLM и OCR, платежные и регуляторные сервисы.

При добавлении новых зависимостей обновить этот файл до финальной передачи кода в общий репозиторий команды.
