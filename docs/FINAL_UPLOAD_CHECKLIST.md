# Перед загрузкой в существующий GitHub-репозиторий

- [ ] Сделать резервную копию опубликованного `index.html`.
- [ ] Распаковать ZIP и загрузить **содержимое архива**, а не сам архив одной записью.
- [ ] Убедиться, что `index.html`, `Dockerfile` и `README.md` видны **в корне** репозитория.
- [ ] Сохранить текущую настройку Pages: `main` → `/(root)`.
- [ ] Проверить адрес https://vagner2203-cell.github.io/alfa-pulse-staff/ в браузере на ноутбуке.
- [ ] Пройти ручные тесты ST-01–ST-09 из `tests/TEST_PLAN.md`.
- [ ] Проверить `docker compose up --build -d` на ПК с Docker Engine.
- [ ] Убедиться, что в документации API обозначен как **DRAFT**, а не реальный сервер.
- [ ] Отправить команде ссылку на репозиторий и полный commit SHA (снять в GitHub после загрузки).
- [ ] Перенести staff-only код в основной командный репозиторий для E2E-интеграции.
