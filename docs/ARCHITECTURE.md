# Архитектура кабинета сотрудника

## Реализовано (AS IS)

GitHub Pages или NGINX в Docker → `index.html` (HTML/CSS/JS) → предопределённый массив из 8 заявок в памяти вкладки → поиск, фильтры, действия сотрудника, история и CSV.

Статический JavaScript не содержит серверной авторизации, контроля доступа, PostgreSQL, загрузки реальных документов или канала синхронизации с клиентским кабинетом. Изменения после F5 исчезают.

См. `diagrams/architecture.png` и исходник `diagrams/architecture.dot`.

## Проект интеграции (TO BE — ещё не реализован)

Кабинет сотрудника → REST API → RBAC, кредитные правила, optimistic concurrency/idempotency → PostgreSQL. Клиентский кабинет обращается к **тому же** API и получает актуальные решения.

Нельзя выдавать будущую архитектуру за текущую реализацию. Детали контрактов представлены в `API_CONTRACT_DRAFT.md` и `openapi-draft.yaml`.
