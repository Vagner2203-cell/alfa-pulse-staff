# Границы финального вклада — ALFA PULSE Staff

## Что можно подтверждать как реализацию

- Отдельный опубликованный сайт с демонстрационным desktop-first интерфейсом.
- Восемь синтетических заявок, поиск, фильтры, карточка скоринга и причин, локальные решения и альтернативное предложение, CSV.
- Исходный код, инструкция, Docker-конфигурация **только для статической страницы**, тестовая документация и схемы.

## Что нельзя утверждать как выполненное

- Общий кредитный конвейер клиент ↔ сотрудник, действующее API и PostgreSQL.
- Серверный скоринг, серверная авторизация, audit log в БД, реальные загрузка и проверка документов.
- Подписание договора и моделируемая выдача в реальном едином процессе.
- Проверка Docker на машине жюри (не выполнена при подготовке архива).

## Связь с требованиями исходного кейса

Требования страницы 6 исходного PDF: GitHub с историей и SHA; воспроизводимый Docker всех компонентов; зафиксированные версии; README; синтетика и роли; THIRD_PARTY_NOTICES; архитектура, API/OpenAPI, коллекция, схемы и тестовые сценарии. Этот архив закрывает **документирование части сотрудника**, а не полную интеграционную сдачу. `openapi-draft.yaml` и Postman collection относятся к проекту backend.

**На финальной защите:** показать сайт сотрудника отдельно, а затем (после интеграции, если будет готова) работу общего backend. Объяснить текущий уровень готовности без завышения.

**Commit SHA:** фиксируется командой после размещения файлов на GitHub; исходный архив сам по себе SHA не имеет.
