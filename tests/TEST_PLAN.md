# Матрица приёмки staff-only

| ID | Тест | Ожидается | Статус до ручного прогона |
|---|---|---|---|
| ST-01 | Открыть сайт на ПК | Заголовок и очередь | Не проверено вручную |
| ST-02 | Поиск AP-1048 | Целевая запись | Не проверено вручную |
| ST-03 | Фильтр «Нужны документы» | Только соответствующие записи | Не проверено вручную |
| ST-04 | Открыть карточку | Поля, балл, причины, история | Не проверено вручную |
| ST-05 | Предложить условия | Изменение суммы/срока и статуса | Не проверено вручную |
| ST-06 | Одобрить/отказать | Локальное обновление статуса | Не проверено вручную |
| ST-07 | CSV | Скачивается файл со строками | Не проверено вручную |
| ST-08 | Сброс демо | Исходные данные восстановлены | Не проверено вручную |
| ST-09 | Обновить браузер | Демо-изменения исчезли | Известное ограничение |
| INT-01 | Ролевой доступ staff | 401/403 для неавторизованного | Не реализовано |
| INT-02 | Решение в клиентском кабинете | Одинаковый серверный статус | Не реализовано |
| INT-03 | Данные после перезапуска | История и документы сохранены | Не реализовано |
| INT-04 | Серверные переходы | Недопустимое действие → HTTP 409 | Не реализовано |

Дополнительно: `npm test` выполняет *структурные* автоматические проверки файла HTML, синтетических данных, обязательных областей интерфейса и базовой Docker-конфигурации. Это **не** заменяет ручную проверку в браузере.
